# 888 足球数据采集器

本地采集 500 与澳客公开竞彩页面，按销售日保存五玩法赔率、赛果和原始证据。使用 Python 标准库，无需安装第三方依赖。

## 下载与运行

1. 在本仓库点击 **Code → Download ZIP**，解压整个文件夹。
2. Windows 需要 Python 3.10 或更新版本。安装时勾选 **Add Python to PATH**。已有可用 Python 或本机 Codex Python 环境时可直接运行。
3. 双击 **start.bat**，浏览器会打开本地采集界面。
4. 选择销售日及数据来源，点击“开始采集”。完成后打开报告，可下载赔率和赛果 CSV。

启动器会检测本机 Python；仓库不包含 Python 安装包。界面仅监听 `127.0.0.1`。

## 当前功能

- 500、澳客五玩法：胜平负、让球胜平负、总进球、半全场、比分，每场以 54 项为完整度基准。
- 按来源显示比赛数量、赔率数量、完赛状态、90 分钟比分、五玩法赛果。
- 500 可读取半场精确比分。澳客竞彩页提供半场胜平负，精确比分未取得时明确留空。
- 加时、点球与 90 分钟结果分开；缺失数据不填零，不根据销售截止推断完赛。
- 原始 HTML、JSON、赔率 CSV、赛果 CSV、HTML 报告、SQLite 归档及 SHA-256 校验。
- 两站身份或数据冲突保留待核对，不自动覆盖。

数据保存到程序内的 `data/`，不上传 GitHub。每次采集独立归档。
目前是赔率及赛果采集工具，24 维基本面尚未采集，不是完整 888 分析数据包。
休市日历中的 2026-10-01 至 2026-10-04 来自用户提供，仅适用于对应年份。

## 更新

最新版保存在 `main` 分支。下载新版 ZIP 后，关闭旧程序，将自己的 `data` 文件夹保留或复制到新版目录，再运行 `start.bat`。不要把不同版本程序文件混用。

使用 Git 的用户可克隆仓库，后续在工作区无未提交修改时运行 `git pull --ff-only`。更新后重新启动程序。
