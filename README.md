# 888 足球数据采集器

当前版本：**v1.3.0**。一个完整程序包，两个操作入口，共用同一套采集逻辑和数据。

[下载正式版本](https://github.com/HolmesQAQ/888-football-collector/releases/latest) · [更新日志](CHANGELOG.md) · [v1.3.0说明](releases/v1.3.0.md) · [版本管理](RELEASING.md)

## 下载运行

下载 Release 中的 ZIP 并完整解压到可写目录，然后任选一个入口：

| 入口 | 操作方式 |
| --- | --- |
| `start.bat` | 纯命令行，输入菜单数字操作 |
| `start-web.bat` | 浏览器可视化界面 |

建议 Windows 10/11。优先复用可用的 Python 3.10+；缺少环境时自动从 [Python官网](https://www.python.org/downloads/windows/) 下载嵌入式运行环境，核对固定SHA-256后安装到程序内 `.runtime`。无需管理员权限，不修改系统PATH，无第三方Python依赖。首次准备环境和在线采集需要联网。已实测x64；x86/ARM64配置尚未实机验证。

## 两版共有功能

- 选择销售日及500、澳客或双来源，采集五玩法赔率、完赛状态及90分钟赛果。
- 精简展示：相同数值只显示一次；不同值、单站缺项注明来源。名称待核对的记录仅作为候选对照，不视为已确认同场。
- 完成后直接打开本轮文件夹，也可打开数据总目录。
- 查看历史结果，验证归档完整性。
- 清除历史：显示范围，输入 `CLEAR` 后永久删除采集目录及数据库，程序、Python环境、运行日志保留。
- 两版共享操作锁，防止同时采集或清理。升级前请关闭仍在运行的旧版。

## 看哪些文件

供 AI 分析请提供每轮目录的 **ai_input.json**。战绩按目标日期过滤，当前未注明日期积分不能当作历史赛前排名。

人工查看优先查看每轮目录中的 **先看这里.txt** 和 **汇总.csv**。原始分站赔率、赛果、JSON、HTML和raw证据仍完整保存，HTML中原始详情默认折叠。

历史都在 `data/`，不会上传GitHub。不同解压目录的数据相互独立。v1.0.0旧报告不改写，可在新程序历史功能中查看动态汇总。

目前不是完整888分析数据包：已接入500最多100条战绩、主客场分组、窗口内交锋、页面未来赛程及当前页面积分，24维基本面尚未完整；澳客半场精确比分未取得；网络或源站限制可能导致缺项。休市日历只适用于明确列出的年份和日期。

## 更新与回退

最新版开发代码在main，稳定版以Releases为准。关闭旧程序，备份data，解压新版后把旧data复制到新版目录。回退时使用原版本和升级前备份，不混用不同版本程序文件。旧版本标签及附件保持不变。
