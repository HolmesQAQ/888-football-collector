# v1.3.1 — 历史战绩只保留一个月

按用户要求，历史战绩统一限制为目标比赛日前一个自然月：包含上月对应日，排除比赛当天；上月无对应日期时取月末。例如9月30日比赛使用8月30日至9月29日，3月31日使用2月末至3月30日。

近3/5/10场、主客场分组、历史交锋和上一场日历间隔均在此范围内计算，不足场数不使用更早记录补齐。snapshot.json、ai_input.json、数据库及报告内的结构化战绩同步过滤。源站接口仍可能返回100条，原始响应仅在raw中作为校验证据保留。未来赛程规则保持不变。

两种入口共用规则；旧归档不改写，重新采集生效。新增跨年、闰年、月末及不足场数测试，43项测试通过。
