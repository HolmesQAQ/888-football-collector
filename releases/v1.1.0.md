# 888 足球数据采集器 v1.1.0

发布日期：2026-10-03

## 下载与两个入口

下载附件 `888-football-collector-v1.1.0.zip`，完整解压到可写目录。

- `start.bat`：纯命令行菜单，不打开网页。
- `start-web.bat`：原浏览器可视化界面。

无需手动安装环境：优先使用已有Python，没有时从Python官网下载专用嵌入式环境并核对SHA-256，不需管理员权限。首次准备环境需要联网。建议Windows 10/11，本地已实测x64；x86和ARM64提供下载配置但尚未实机验证。

## 共同功能

- 按日期和来源采集500、澳客赔率及赛果。
- 相同字段只显示一次，差异及单站缺项注明来源；身份不确定时标为候选对照，保留两站名称及全部原始记录。
- `先看这里.txt` 与 `汇总.csv` 为优先查看文件，HTML原始详情默认折叠。
- 采集后直接打开本轮目录，同时保留打开总目录。
- 查看历史、校验文件、清除历史：输入CLEAR后才永久删除采集归档及数据库，程序/环境/日志保留。
- 跨窗口采集和清理互斥，操作失败会说明原因。

## 升级、回退及验证

关闭旧版窗口，备份data，解压新版，将旧data复制到新版程序目录即可。原归档不改写，新功能不要求迁移；回退请使用v1.0.0及升级前备份。两个入口在同一个解压目录共用数据。

已验证自动环境准备、下载校验失败拦截、终端菜单、历史清理及网页HTTP流程；发布流程运行Windows Python 3.10和3.12回归测试。ZIP附SHA256SUMS.txt供校验。

已知限制：24维基本面尚未采集；澳客半场精确比分未取得；源站限制可能导致缺项。历史清理是永久删除，请先备份需要保留的数据。
