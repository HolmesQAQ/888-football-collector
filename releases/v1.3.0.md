# v1.3.0 — 扩展原站战绩、交锋与赛程

继续使用500及澳客，不引入体彩替代来源。命令行和网页共用新增能力。

- 接入500球队赛程页自身的近100场公开接口；校验响应球队ID、逐场双方及比赛ID、完赛标记、日期和重复冲突。扩展请求失败保留首页结果。
- 按目标比赛日期排除本场、同日和未来战绩，导出近3/5/10场、主客列表、窗口内交锋、此前10天比赛列表及上一场日历间隔。
- 读取球队首页未来赛程，输出目标日后10天的页面可见记录。当前观察不证明历史赛前已知；空列表不证明没有赛程。
- 保留百场接口附带的欧赔、亚盘、大小球原始观察值；没有报价时间，不能当作目标比赛赔率或完整变化历史。公司/口径未确认时保持标注。
- 主客字段仅指列表位置，未验证实际场地或中立场；日历间隔不等于真实休息小时。
- 积分仍为首页未注明日期快照，独立保留其来源地址与采集时间。

## 测试与范围

42项测试通过，新增百场响应身份、重复冲突、未完赛过滤、交锋双窗口一致性、赛程时间范围和扩展失败回退测试。在线验证使用2026-09-30双站两场比赛。

本轮调查：澳客欧赔HTML可返回，但赔率数据请求及历史、亚盘、阵容、情报等已测试详情路径返回405；500分析页返回验证页。该结论是本次请求状态，不表示网站没有这些数据。500球队阵容页可读取，但样本分组和球员位置不一致、赛季信息未确认，尚未作为可靠阵容接入。

伤停、正式首发、历史积分、完整赔率变化尚未接入；ready_for_analysis仍为false。
