# 888 足球数据采集器 v1.0.0

发布日期：2026-10-03

首个正式版本：支持500、澳客五玩法赔率及赛果采集，提供Windows启动器和本地浏览器界面。

## 下载与运行

下载附件 `888-football-collector-v1.0.0.zip`，完整解压后双击 `start.bat`。需要 Python 3.10+，不需要安装第三方 Python 库。`SHA256SUMS.txt` 可用于核对压缩包完整性。

## 本版内容

- 两站比赛、五玩法赔率、完赛状态、90分钟比分及五玩法实际结果。
- 500半场比分；澳客半场胜平负和缺项说明。
- JSON、赔率CSV、赛果CSV、HTML报告、SQLite和原始页面归档。
- 程序界面与新快照记录版本；来源冲突、未取得的数据明确保留。

## 升级与回退

关闭旧程序，先备份自己的 `data` 目录，再解压新版本。需要保留历史时把 `data` 复制到新版目录；不覆盖或删除个人数据。回退时从 Releases 下载原版本并使用升级前的数据备份。

## 验证与限制

发布前运行14项回归测试，覆盖日期核验、赔率解析、数据冲突、赛果、点球排除及归档完整性。发布流程要求 Windows Python 3.10、3.12 均通过。

24维基本面尚未采集；澳客半场精确比分未取得；数据仍为来源观察，尚非独立官方核验。休市日历只适用于文件中明确列出的年份和日期。
